## 4. Which opportunity types matter most for AI inclusion in B2B software categories, mapped to Quotr?

## 7. Developer and agent surfaces (GitHub research repos, read-only MCP connector): do they improve AI visibility?

### Takeaway
**Weakly supported.** No independent study links MCP servers, ChatGPT/Claude app-directory listings or GitHub repos to more brand mentions in AI answers. Brand-level MCP adoption is about 1%, and the claims come from vendors selling MCP services. Use GitHub only as a mirror for datasets and benchmarks. Defer an MCP connector until reviews, lists and data assets are in place, or build it as a product feature, not a GEO tactic.

### Cited Findings
- A 908-brand study cited by Competlab finds MCP Server Cards on 0.7–1.1% of brands; the "brand whose MCP server connects becomes the canonical source" thesis is "asserted, not measured" (search-tool summary); B2B MCP adoption comes mainly through customer success, not directory search — [Competlab](https://competlab.com/ai-visibility/ai-visibility-guide-2026); [Presenc](https://presenc.ai/research/mcp-server-ecosystem-statistics-2026).
- Estimates of 8,000–12,000 public MCP servers (Q2 2026); sources selling MCP listings (e.g., MCPBundles) are commercial — [Presenc](https://presenc.ai/research/mcp-server-ecosystem-statistics-2026); [MCPBundles](https://www.mcpbundles.com/business/managed-mcp-apps).
- Coding agents made 10% of the few llms.txt requests Ahrefs observed, so agent-oriented files are read mostly by developer tools, not answer engines — [Ahrefs](https://ahrefs.com/blog/llmstxt-study/).

### Inferences
- **GitHub repo (worth it as a vehicle, not a lever):** `quotr-ai/factory-direct-price-index` and `quotr-ai/ai-takeoff-benchmark` with CSV, methodology README, a CITATION.cff file and a Zenodo DOI. This gives journalists and list writers a stable, citable artifact, which is the mechanism that plausibly helps. Effort: 0.5 day per repo once the data exists.
- **Read-only MCP connector:** for example "Quotr material price lookup" (returns index values by category/quarter) or "takeoff status" for customers. Value for GEO is speculative. It might matter later if assistants start routing product questions to connected tools. Effort: 3–10 dev days plus security review. Recommend post-90-day, only if customers ask for it.

### Gaps
- No primary study measuring the effect of MCP or app-directory presence on organic AI answer inclusion exists in what I found.
