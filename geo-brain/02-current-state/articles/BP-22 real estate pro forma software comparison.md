## What it covers

Compares three ways to build a development pro forma: Excel ("the disconnected grid"), Aprao ("the cloud financial wrapper") and Quotr.ai ("the unified physical-to-financial platform"). It argues that Excel and Aprao need hard costs typed in from a separate takeoff in a tool like Bluebeam or PlanSwift, while Quotr takes quantities from the drawings and feeds them into a pro forma backed by procurement pricing. *(from web search results)*
